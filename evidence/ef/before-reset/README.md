# Before the devnet reset

The EIP-8141 alt-mempool devnet (chain 1337) was reset on 6 Nov 2026 at 11:59 IST (new genesis at 06:29 UTC). These files record the first runs, made before the reset: the first frame transaction (leaf 1, block 403,931), the leaf-0 dry run, the rescue dry runs and two explorer screenshots. Those transactions are no longer on the chain.

Every demo was re-run on the fresh chain the same day. The current evidence is in the parent folder (`frame-demo-leaf2.json`, `rescue.json`, `paymaster-guards.json`, `forgery.json`, ...).
