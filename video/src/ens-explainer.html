2 · Who can steer a name (ENSv2)

Five hands on the wheel.

1 Owner: holds the name itself key
2 Helpers: given roles, like "change resolver" key
3 Operators: allowed to move all your names key
4 Resolver crew: can change the address it points to key
5 Port authority: the registry above .eth key
3 · The resolver trap

Moving the name isn't enough.

The name (hand 1)

You transfer it to a safe wallet.

old key 🔓

The resolver (hand 4)

It holds the address records. A transfer doesn't touch it.

old key 🔓

The old key can still change the address: payments go wherever it says.

4 · What Lifeboat's Helm check does

Find every hand, prove none is missing.

  • 1 Find the name's registry and its resolver
  • 2 Read every "roles changed" event, to rebuild who holds which role
  • 3 Add those roles up: the registry keeps its own total. They must match: Proven complete
  • 4 Check each key: has it ever signed? Then its public key is out: exposed
  • 5 Any exposed key on hands 1-4 means: Hijackable on Q-Day
5 · The way out (our test name, lifeboatpq.eth)

A handover the registry checks.

  • ✗ Plain transfer: the registry refuses, because a helper still holds a role
  • 1 Give the post-quantum wallet its own new resolver
  • 2 Point the name at the new resolver (escapes the trap)
  • 3 Remove the helper's role, and the operator
  • ✓ Now the transfer: the registry accepts it
  • 5 The new wallet signs its own record with a quantum-safe signature
